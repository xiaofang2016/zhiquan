# 职圈前端接口

给 Web / H5 / App 用。HTTP 业务在 im-platform，实时消息在 im-server 的 WebSocket。聊天内容走 HTTP 发送，再由 WebSocket 推给在线端。

说球帝账号怎么登录、比赛、资料库和个人中心打哪几个地址，看《职圈前端接入》。这篇只列职圈自己的聊天接口。不要看 `https://zhiquan.78chat0.com/api/v3/api-docs`。

## 地址

H5 和 App 都用这个域名。2026-09-30 已从外网测通：登录接口能进到职圈后端，WebSocket 握手返回 101。

| 用途 | 地址 |
|---|---|
| HTTP | `https://zhiquan.78chat0.com/api` |
| WebSocket | `wss://zhiquan.78chat0.com/im` |

页面和接口放在同一域名下时，也可以用相对路径 `/api`、`/im`。`chat.7pgb88.com` 和 `chat-h5.7pgb88.com` 仍是 78Chat 老后端，不要切过来。

`/api` 已经转到新进程。`POST /login/sport` 走这个域名即可。WebSocket `/im` 仍是原来的消息服务。

## 通用约定

成功时 HTTP 状态码一般是 200，业务结果看 JSON 里的 `code`。

```json
{
  "code": 200,
  "message": "成功",
  "errorCode": null,
  "data": {}
}
```

前端只把 `code == 200` 的 `data` 当成功结果。`code != 200` 时展示 `message`。

| code | 含义 | 前端处理 |
|---|---|---|
| 200 | 成功 | 取 `data` |
| 400 | 未登录 | 回登录页 |
| 401 | accessToken 失效 | 用 refreshToken 换新 token，再重放刚才的请求 |
| 410 | 接口已停用 | 改密、重置密码走 aagames，不要再调这两个接口 |
| 500 | 服务端异常 | 展示 `message`，常见文案是「系统繁忙，请稍后再试」 |
| 10001 | 用户名不存在或密码错误 | 展示 `message` |
| 10003 | 用户名已注册 | 展示 `message` |
| 10004 | 参数含非法内容 | 展示 `message` |

时间字段：消息的 `sendTime` 是毫秒时间戳。用户封禁时间 `unbanTime` 是字符串 `yyyy-MM-dd HH:mm:ss`。

### 请求头

登录之后，除下面「免登录」接口外，每个请求都带：

| Header | 值 |
|---|---|
| `accessToken` | 登录返回的 accessToken。现有 Web 端会先 `encodeURIComponent` |
| `Accept-Language` | `zh` 或 `en`，错误文案按这个返回 |
| `X-Locale` | 同上 |
| `x-device-type` | 端类型，自行约定 |
| `x-version-code` | 应用版本号 |
| `Content-Type` | JSON 接口用 `application/json`；上传用 `multipart/form-data` |

刷新 token 时额外带请求头 `refreshToken`，不要放在 body 里。

### 终端 `terminal`

| 值 | 端 |
|---|---|
| 0 | Web / H5 |
| 1 | App |
| 2 | PC |
| 3 | 内嵌客服 |

同一账号可以多端在线。账号密码登录时，同一 `terminal` 再次登录会把该端旧连接踢下线，WebSocket 收到 `cmd = 2`。`POST /login/sport` 不会踢已经登着的会话。这次上线前签发的 accessToken、refreshToken 也会下线，不能续期。说球帝令牌还有效时，客户端再调 `POST /login/sport`。

App 用 `1`。H5 页面用 `0`。小程序里跳进客服时用 `3`，这样不会把外层 App 挤下线。

### 商户号

登录、注册、SSO 都必须带 `merchantNo`。当前开通的是 `10011`、`10012`。空值或未开通商户会失败，文案是「商户号不可为空」或商户不可用。

### 免登录

这些接口不要带登录态，带了也不校验：

`/login`、`/login/external`、`/login/guest`、`/login/sso`、`/login/sport`、`/register`、`/refreshToken`、`/resetPwd`、`/captcha/**`、`/system/**`、`/image/upload`、`/video/upload`、`/file/upload`、`/talk/**`

## 登录

### 账号密码

`POST /login`

```json
{
  "terminal": 0,
  "merchantNo": "10011",
  "userName": "testmike",
  "password": "12345678"
}
```

`userName` 可以是用户名、手机号或邮箱。密码在 aagames 校验，职圈本地不存密码。

`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| accessToken | string | 之后放在请求头 |
| accessTokenExpiresIn | number | 秒 |
| refreshToken | string | 过期后续期 |
| refreshTokenExpiresIn | number | 秒 |

登录成功后立刻做两件事：调 `GET /user/self` 拿用户资料，并连接 WebSocket。

### 已有 aagames token

`POST /login/external`

```json
{
  "terminal": 0,
  "merchantNo": "10011",
  "accessToken": "<aagames 的 access_token>"
}
```

返回同上。这里的 `accessToken` 是 aagames 颁发的，不是职圈自己的。

小程序里打开客服时，`terminal` 传 `3`。外层 App 仍是 `1`，两边可以同时在线。

### 未登录客服

`POST /login/guest`

忘记密码、还没有游戏 token 时用。不创建 aagames 账号。

```json
{
  "terminal": 3,
  "merchantNo": "10011",
  "deviceId": "16到64位字母数字"
}
```

`merchantNo` 允许 `10011`、`10012`、`sport`。`sport` 进客服美美，不创建说球帝账号。同一 `deviceId` 再次打开会复用原来的访客。返回和普通登录一样的 `accessToken`、`refreshToken`。

访客可以和客服对话。查余额、流水、活动、领彩金都不行，这些要先登录游戏站。

### 说球帝账号

给已经接了说球帝登录的 App 用。用户在说球帝注册或登录之后，把说球帝返回的 `token` 原样交给职圈，换职圈自己的登录态。不要再拼 `z` + 说球帝 `userId` 前 11 位去调 `POST /login`，也不要带商户号 `10011` / `10012`。吉祥、UED 里原来的聊天账号不再使用。

职圈自己的登录页也只收手机号。登录提交手机号和密码，先请求说球帝 `POST /prod-api/user/login`；注册先请求 `POST /prod-api/user/sms`，再请求 `POST /prod-api/user/register`。说球帝返回 `token` 之后，都调下面这个接口。

`POST /login/sport`

免登录。请求体：

| 字段 | 必填 | 说明 |
|---|---|---|
| token | 是 | 说球帝 `POST /prod-api/user/login` 或注册接口返回的 `token`。30 天有效，过期后先在说球帝重新登录，再拿新 token 调本接口 |
| terminal | 否 | `0` Web / H5，`1` App，`2` PC，`3` 内嵌客服。不传默认 `0`。App 传 `1` |

```json
{
  "terminal": 1,
  "token": "<说球帝登录令牌>"
}
```

成功时 `code` 为 `200`，`data` 与账号密码登录相同：

| 字段 | 类型 | 说明 |
|---|---|---|
| accessToken | string | 之后每个业务请求放在请求头 `accessToken` |
| accessTokenExpiresIn | number | 秒 |
| refreshToken | string | 过期后续期 |
| refreshTokenExpiresIn | number | 秒 |

```json
{
  "code": 200,
  "message": "成功",
  "errorCode": null,
  "data": {
    "accessToken": "<职圈 accessToken>",
    "accessTokenExpiresIn": 1800,
    "refreshToken": "<职圈 refreshToken>",
    "refreshTokenExpiresIn": 604800
  }
}
```

上面的过期秒数沿用职圈现有配置，前端以本次返回值为准，不要写死。

拿到 token 后的顺序与普通登录相同：`GET /user/self`，拉好友、群和离线消息，再连 WebSocket。续期仍是 `PUT /refreshToken`，请求头带 `refreshToken`。

`GET /user/self` 里和说球帝相关的字段：

| 字段 | 说明 |
|---|---|
| id | 职圈聊天用户 id。不是说球帝 `userId`，也不是吉祥 `j_users.id` |
| userName | `s` 加说球帝 32 位 `userId`。前端不要展示，也不要拿它去调 `/login` |
| nickName | 说球帝昵称。说球帝没昵称时是手机号中间四位打码。用户在职圈改过且说球帝仍是打码号时，再次登录保留职圈昵称 |
| phone | 说球帝手机号 |
| headImage / headImageThumb | 说球帝头像。登录时已拼成说球帝基址开头的完整地址 |
| type | `5`，表示说球帝账号 |
| merchantNo | 固定 `sport`。不是 `10011` 或 `10012` |

同一个人再次登录会复用原来的聊天用户。头像、手机号每次登录都用说球帝的最新资料覆盖。昵称在说球帝仍是打码手机号、且用户已在职圈改过时不再覆盖。说球帝改了手机号之后，再调一次本接口，职圈手机号写成说球帝当时的号码。这次登录不会把别的端踢下线。

失败时 HTTP 仍是 200，看 JSON 的 `code` 和 `message`：

| 情况 | code | message |
|---|---|---|
| 没传 token，或 token 为空 | 500 | 请先登录。英文是 Please log in first |
| 说球帝认为没登录、令牌对不上 | 400 | 请先登录。英文是 Please log in first |
| 说球帝令牌超过 30 天 | 400 | 登录已过期。英文是 Login has expired |
| terminal 不在 0–3 | 500 | 登录终端类型取值范围:0,3 |
| 说球帝暂时连不上 | 500 | 说球帝暂时无法登录 |
| 账号被封禁 | 500 | 账号已被封禁 |
| 账号已注销 | 500 | 账号已注销 |

`code != 200` 时把 `message` 展示给用户。`400` 且文案是「请先登录」或「登录已过期」时，回到说球帝登录，不要用职圈的账号密码页重试。

说球帝账号发红包 `POST /redpacket/send`、领红包 `POST /redpacket/{redpacketId}/claim` 使用说球帝余额。余额不够时 `message` 为「余额不足」。领取记录仍是 `GET /redpacket/{redpacketId}/records`。活动红包不进说球帝余额。

### SSO

`POST /login/sso`

```json
{
  "ssoCode": "<一次性 code>",
  "merchantNo": "10011",
  "terminal": 0
}
```

`terminal` 可省略，默认 0。`ssoCode` 用一次即失效。

### 刷新

`PUT /refreshToken`

请求头：`refreshToken: <登录返回的 refreshToken>`

成功后 `data` 仍是上面的登录对象，两个 token 都要换成新的。刷新失败则回登录页。

### 注册

`POST /register`

```json
{
  "mode": "username",
  "merchantNo": "10011",
  "userName": "name",
  "password": "123456",
  "confirmPassword": "123456",
  "nickName": "昵称",
  "lot_number": "",
  "captcha_output": "",
  "pass_token": "",
  "gen_time": ""
}
```

`mode` 还可以是 `phone`、`email`，对应填 `phone` 或 `email`。极验四个字段必填，字段名用下划线。密码长度 5–20，用户名最长 20。成功时 `data` 为空，前端再调一次 `/login`。

### 退出与停用接口

| 方法 | 路径 | 说明 |
|---|---|---|
| DELETE | `/unregister` | 只清职圈登录态，不影响 aagames 账号 |
| PUT | `/modifyPwd` | 已停用，返回 410 |
| PUT | `/resetPwd` | 已停用，返回 410 |

## 启动顺序

1. `POST /login`（或 external / sso）
2. `GET /user/self`
3. `GET /friend/list`、`GET /group/list`
4. `GET /message/private/loadOfflineMessage`、`GET /message/group/loadOfflineMessage`、`GET /message/system/loadOfflineMessage`
5. 连接 `ws://.../im`，发送 `cmd = 0`

`GET /system/config` 不需要登录，可在登录页之前拉。里面有 WebRTC、注册开关、极验 `captchaId`、是否审核中。

`GET /system/checkVersion?version=` 返回 `isLatestVersion`、`changeLog`。

和原站群同号的是同一套编号，会跟着抓取变。从 1240 起的旧群是另一套编号，不会跟着变。置顶、免打扰用原站列表里的数字 `id`。成员表里没有这个人时，开关记在偏好里，`/group/list` 和 `/group/find/{id}` 读的是这份偏好。没设过的群保持原来的值。

复制群里没入群的人可以撤回自己发的那条。历史里这条的 `status` 会变成撤回。删消息仍只对自己隐藏。

## 消息

发送、历史、离线都走 HTTP。在线推送走 WebSocket 的 `cmd = 3`（私聊）和 `cmd = 4`（群聊）。

### 发私聊

`POST /message/private/send`

```json
{
  "localId": "前端雪花 id",
  "recvId": 40,
  "content": "你好",
  "type": 0,
  "quoteMessageId": null
}
```

`recvId`、`content`、`type` 必填。普通文字最长 1024。`data` 是私聊消息对象。

### 发群聊

`POST /message/group/send`

```json
{
  "localId": "前端雪花 id",
  "groupId": 1,
  "content": "大家好",
  "type": 0,
  "receipt": false,
  "atUserIds": [40],
  "quoteMessageId": null
}
```

`atUserIds` 最多 20 个。`content` 最长 10240。

图片、文件、语音、视频要先上传，把返回的 URL 放进 `content`，`type` 用对应类型。

原站复制群和原站是同一个群号，历史来自抓取。登录后同样用这条发送，人不在群成员里也能发。留言记在职圈自己的消息里，打开这个复制群的人看得到，不发回原站。

### 消息对象

私聊：`id`、`localId`、`seqNo`、`sendId`、`recvId`、`content`、`type`、`quoteMessage`、`status`、`sendTime`、`deleted`。

`seqNo` 在单个会话内递增。私聊会话由双方用户 id 组成，前端用 `localId` 对齐自己刚发出、服务器尚未回包的消息。

```json
{
  "files": [
    {
      "fileLength": 151069,
      "fileMd5": "2273f7d8-b931-4b58-95da-ec9022eaa352.png",
```

## WebSocket

地址：`wss://zhiquan.78chat0.com/im`。同域名页面也可以连相对路径 `/im`。

每一帧：

```json
{ "cmd": 0, "data": {} }
```

连接 `onopen` 后立刻发登录，收到 `cmd = 0` 才算登录成功，然后开始心跳。

```json
{ "cmd": 0, "data": { "accessToken": "<职圈 accessToken>", "devId": 123456 } }
```

`devId` 本机随机整数即可。心跳每 20 秒一次：

```json
{ "cmd": 1, "data": {} }
```

服务端回 `cmd = 1` 后重置计时。断线后约 15 秒重连，重连成功要重新发 `cmd = 0`。

| cmd | 方向 | 含义 |
|---|---|---|
| 0 | 双向 | 登录。客户端发 token，服务端回同一 cmd 表示成功 |
| 1 | 双向 | 心跳 |
| 2 | 服务端 → 客户端 | 被踢下线。清 token，回登录页，不要重连 |
| 3 | 服务端 → 客户端 | 私聊消息，`data` 是私聊消息对象 |
| 4 | 服务端 → 客户端 | 群消息，`data` 是群消息对象 |
| 5 | 服务端 → 客户端 | 系统消息。好友申请、已读、撤回、群事件都在这里，看 `data.type` |

客户端不通过 WebSocket 发聊天内容。聊天一律 `POST /message/private/send` 或 `POST /message/group/send`。

## 音视频

信令走 HTTP，媒体走 WebRTC。ICE 配置从 `GET /system/config` 的 `webrtc` 取。

单人，前缀 `/webrtc/private`：

`POST /setup`、`/accept`、`/reject`、`/cancel`、`/failed`、`/handup`、`/offer`、`/answer`、`/candidate`、`/heartbeat`、`/device`，以及 `GET /info`。

多人，前缀 `/webrtc/group`：上面一组，另有 `/join`、`/quit`、`/invite`。`GET /webrtc/group/info?groupId=` 看当前群通话。

呼叫结果会同时以消息类型 100–110、200–212 从 WebSocket 推到对端。
